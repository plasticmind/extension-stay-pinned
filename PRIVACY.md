# Stay Pinned privacy policy

Last updated: November 10, 2026

Stay Pinned is a Chrome extension that opens the same pinned tabs in every new browser window. This policy describes what data Stay Pinned uses and where that data goes.

## Summary

Stay Pinned doesn't send your data to the developer or to anyone else. It has no servers, analytics, ads, or third-party code, and it makes no network requests.

## Data Stay Pinned uses

Stay Pinned uses the following data, only on your device and only to manage your pinned tabs:

- **Your saved pinned tabs.** When you save a window's pinned tabs, or edit the list on the options page, Stay Pinned stores each tab's URL and title. It uses this list to open the same pinned tabs in each new window and to reset them.
- **The URLs of tabs in your open windows.** Stay Pinned reads the URL of each tab in a window to find the tabs that match your saved list. It reads them when a window opens, when Chrome starts, and when you save or reset pinned tabs. It doesn't keep a history of the pages you visit.
- **Which tab belongs to which saved entry.** For each open window, Stay Pinned records which tab matches which saved entry, so that it can reset the window without opening duplicates. Chrome deletes this record when you close the window or restart the browser.
- **Site icons.** Stay Pinned shows each saved site's icon from Chrome's own favicon cache. It doesn't download icons.

## Where the data is stored

Stay Pinned stores your saved list in Chrome sync storage. If you turned on Chrome sync, Chrome syncs the list to other computers where you use Stay Pinned, as part of your Google Account's Chrome sync data. Google's privacy policy covers Chrome sync. The developer of Stay Pinned has no access to that data.

Stay Pinned stores the tab records for open windows in Chrome session storage, which stays on your device and clears when Chrome restarts.

## What Stay Pinned doesn't do

- It doesn't collect, sell, share, or transfer your data to the developer or to any third party.
- It doesn't use your data for advertising, analytics, or credit decisions.
- It doesn't read or change the content of the websites you visit. It has no host permissions.
- It doesn't run remote code.

## Delete your data

To delete your saved list, remove the tabs on the Stay Pinned options page and click **Save**, or uninstall the extension. Uninstalling Stay Pinned removes the data it stored from this computer.
