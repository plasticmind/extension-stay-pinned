Stay Pinned

Stay Pinned opens the same set of pinned tabs in every new Chrome window. A keyboard shortcut resets them to their saved pages.

    How it works

    • Every new window opens with your pinned tabs, in order.
    • Resetting a window reopens pinned tabs you closed, pins tabs you unpinned, puts them back in order, and returns each one to its saved page. It also closes the pinned tab for any entry you removed from this list.
    • If a URL redirects, such as a sign-in page, its tab reloads every time you reset. To avoid that, save the pinned tabs from a window instead of typing URLs. Saving records the page where each tab ends up.
    • Titles can be up to 100 characters long.
    • Stay Pinned doesn't change or close tabs that you pin by hand. They stay to the right of the tabs in this list.
    • Changes to this list apply to new windows. To apply them to a window that's already open, reset its pinned tabs.
    • Each window has its own copy of each pinned tab, so browsing in one window doesn't change the others.
    • Incognito windows and popup windows don't get pinned tabs.
